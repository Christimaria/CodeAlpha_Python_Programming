# CodeAlpha Python Programming Internship

This repository contains three Python projects completed as part of my CodeAlpha Python Programming Internship.

## Tasks Completed

### 1. Hangman Game
A console-based word guessing game where the player guesses letters to find a hidden word within a limited number of attempts.

**Concepts:** Python basics, loops, conditional statements, strings, and random module.

### 2. Stock Portfolio Tracker
A simple application that calculates the total investment value based on stock symbols, quantities, and predefined stock prices.

**Concepts:** Dictionaries, user input, calculations, file handling, and CSV module.

### 3. Basic Chatbot
A rule-based chatbot that responds to simple greetings, questions, and commands.

**Concepts:** Functions, strings, conditional statements, loops, and user input.

## Technologies Used
- Python 3
- Git and GitHub

## How to Run
Open the folder for the task you want to run and execute its Python file:

```bash
python hangman.py
```

```bash
python stock_portfolio.py
```

```bash
python chatbot.py
```

Through these projects, I practised Python programming fundamentals, problem-solving, input validation, file handling, and version control using GitHub.
